# Benford’s Law and LLM-Generated Payment Data

This repository contains the datasets and Python code accompanying a study of first-digit conformity to Benford’s law in synthetic payment data generated by three large language models: Gemini 3.6 Flash, GPT-6 Luna, and Claude Sonnet 5.

Each model was asked to generate 50 datasets containing 500 fictional company payment amounts per dataset, for a total of 150 datasets. The prompt did not mention Benford’s law.

## Repository contents

- `Gemini/`: 50 Gemini datasets, named `Gemini1.csv` through `Gemini50.csv`.
- `ChatGPT/`: 50 GPT-6 Luna datasets, named `GPT1.csv` through `GPT50.csv`.
- `Claude/`: 50 Claude datasets, named `Claude1.csv` through `Claude50.csv`.
- `benford.py`: Analysis and visualization script.
- `requirements.txt`: Required Python packages.
- `Results/`: Saved analysis results and figures used in the paper.

The datasets contain fictional payments, not actual company transactions. Repeated outputs are retained because they arose from separate recorded generation attempts.

## Running the analysis

Use Python 3.10 or later. Download or clone the repository, open a terminal in its main folder, and install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the analysis:

```bash
python benford.py --data-dir .
```

Keep the model folders and filenames unchanged. The script creates a new timestamped folder inside `benford_results/` and preserves the original datasets.

## Analysis

The script evaluates each dataset separately using:

- Total variation distance to measure departure from Benford’s first-digit distribution.
- Pearson’s chi-square screening with 100,000 Monte Carlo simulations and an unadjusted threshold of p < 0.05.
- Bootstrap confidence intervals for each model’s mean total variation distance, using 20,000 resamples of whole datasets.
- Duplicate detection to describe repetition across generation attempts.

Positive amounts recorded with one or two decimal places are accepted. The script also produces figures showing mean first-digit proportions and conformity across individual datasets.

The Monte Carlo reference assumes independent Benford-distributed digits within each dataset. Bootstrap intervals assume independent generation attempts. The findings describe the tested website workflows; conformity alone does not establish authenticity or fraud.
